# Exosting
Is a fork of Exo shell made with the Ignis framework for Niri and Hyprland. The core idea being to fix some bugs and add new functionalities.
Further details will be specified as the project advances.

# Installation
As of right now, the best and simplest way to install Exosting is to follow the automatic installation guide from Exo's readme and replace the content of `~/.config/ignis/` with the content of `./src/`
